# Pourik

Marketing site for Pourik — a marketplace growth consultancy (Amazon,
Walmart, and other retail marketplaces: advertising, catalog optimization,
inventory & pricing strategy) that also owns and sells its own portfolio of
branded products on those same channels.

Built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Structure

- `/` — homepage, dual value prop (consulting + owned brands)
- `/services` — consulting service breakdown
- `/brands` — Pourik-owned product portfolio (placeholder until first launch)
- `/about` — positioning and operating principles
- `/contact` — lead form (opens a pre-filled email; swap in a real form
  handler such as Formspree or Resend once you have a provider)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
